Описание

Sisi Password Manager — это стильный, минималистичный и ультра-безопасный
консольный менеджер паролей (TUI). Он создан для тех, кто живет в терминале,
ценит скорость работы с клавиатуры и эстетику киберпанка.

Главная особенность Sisi — Stateless-генерация паролей. Приложение не хранит
ваши пароли в базе данных. В зашифрованном локальном файле хранятся только
метаданные (название сервиса, логин, длина пароля). Сами пароли генерируются на
лету на основе вашего Master Key и криптографических алгоритмов.

Основные фичи

  - 🟣 Cyberpunk UI: Красивый интерфейс в терминале с неоновой цветовой палитрой
    (Magenta & Cyan), реализованный на фреймворке Textual.
  - 🛡️ Zero-Knowledge Architecture: Ваши реальные пароли нигде не сохраняются.
    Украденный файл базы данных абсолютно бесполезен без вашего Master-пароля.
  - 🥷 Keyboard-Driven: Управление полностью с клавиатуры (горячие клавиши для
    всех действий).
  - 🔍 Умный поиск: Мгновенная фильтрация записей по названию сервиса.
  - 📋 Буфер обмена: Копирование сгенерированного пароля в буфер обмена в один
    клик с авто-очисткой (требуется pyperclip).
  - 🔐 Hardcore Security: Использование AES-GCM для шифрования хранилища и
    Argon2id для деривации ключей и генерации паролей.
  - 🛡️ Атомарные сохранения: Защита от повреждения файла базы данных при
    внезапном отключении питания.

Установка и запуск

Требования

  - Python 3.8 или выше.
  - Зависимости: textual, cryptography, pyperclip (опционально, но
    рекомендуется).

Установка

1.  Клонируйте репозиторий:

    git clone https://github.com/YOUR_USERNAME/sisi-password-manager.git
    cd sisi-password-manager

2.  Создайте и активируйте виртуальное окружение (рекомендуется):

    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    # venv\Scripts\activate   # Для Windows

3.  Установите зависимости:

    pip install textual cryptography pyperclip

4.  Запустите приложение:

    python main.py

Как это работает под капотом

Sisi Manager применяет гибридный подход к хранению данных, обеспечивая
максимальную безопасность:

1.  База данных (sisi.enc):

      - Файл зашифрован с использованием AES-GCM.
      - Ключ для расшифровки вычисляется из вашего Master Key с помощью Argon2id
        (memory-hard алгоритм, защищающий от брутфорса) и уникальной соли
        os.urandom(16).
      - Внутри хранится только JSON с метаданными: {"service": "github",
        "login": "user@mail", "pass_ver": 0, "lnth": 16}.

2.  Генерация паролей:

      - Пароль не читается из файла.
      - Когда вы нажимаете s или g, Sisi берет ваш login, service и version,
        хеширует их через SHA-256 для получения уникальной соли.
      - Затем эта соль и ваш Master Key прогоняются через Argon2id.
      - Полученный криптографический хеш конвертируется в строку нужной длины,
        используя алфавит (a-z, A-Z, 0-9, спецсимволы).
      - Результат: Уникальный, сложный и всегда воспроизводимый пароль, который
        невозможно украсть, так как он существует только в оперативной памяти во
        время работы программы.

Версионирование паролей

Поле Version при добавлении сервиса решает проблему смены паролей. Если вам
нужно обновить пароль для сайта (например, раз в полгода), просто увеличьте
Version (с 0 на 1). Метаданные изменятся, и алгоритм сгенерирует абсолютно новый
пароль на основе того же Master Key!
